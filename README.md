# Spot Welder Firmware - ESP32-C3 SuperMini

این پروژه یک فریم‌ور پیشرفته، ایمن و ماژولار برای کنترل دستگاه نقطه جوش (Spot Welder) بر پایه میکروکنترلر ESP32-C3 است. این سیستم با استفاده از تشخیص عبور از صفر (ZCD) و کنترل ترایاک، جوشکاری دقیق و ایمن را فراهم می‌کند.

## 🏗 معماری نرم‌افزار (Software Architecture)

کد این پروژه به منظور خوانایی بالا، مدیریت آسان‌تر در Git و قابلیت توسعه (Scalability)، از یک فایل یکپارچه (`.ino`) به یک ساختار ماژولار `C++` تفکیک شده است. برنامه کاملاً به صورت غیرمسدودکننده (Non-blocking) نوشته شده و از هیچ‌گونه دستور `delay()` در حلقه اصلی استفاده نمی‌کند.

پروژه به ۶ ماژول اصلی تقسیم شده است:

*   **`Config.h` (پیکربندی پایه):**
    *   مرکز تعریف پین‌های سخت‌افزاری، ثابت‌های سیستم (Constants)، محدودیت‌های ایمنی (Timings & Limits) و کدهای مربوط به State Machine. این فایل باعث می‌شود تغییر سخت‌افزار در آینده تنها نیازمند ویرایش یک فایل باشد.

*   **`WeldEngine.h / .cpp` (هسته پردازشی و ایمنی):**
    *   قلب تپنده دستگاه. این ماژول وظیفه مدیریت State Machine جوشکاری، خواندن وقفه ZCD (تطبیقی با فرکانس شبکه)، شلیک دقیق پالس‌های ترایاک و محاسبه حرارت (Thermal Tracking) را بر عهده دارد.
    *   **تایمر ایمنی (Watchdog):** دارای یک تایمر سخت‌افزاری مستقل (`esp_timer`) است که در صورت قطع شدن سیگنال ZCD یا قفل شدن برنامه، ترایاک را در کمتر از چند میلی‌ثانیه قطع می‌کند.

*   **`UI.h / .cpp` (رابط کاربری و گرافیک):**
    *   مسئولیت تعامل با کاربر از طریق نمایشگر OLED (0.96 inch)، انکودر چرخشی و بازر.
    *   گرافیک این بخش برای محیط‌های صنعتی و کارگاهی بهینه‌سازی شده و از فونت‌های بسیار درشت برای نمایش پارامترهای حیاتی (پالس‌ها و قدرت) بهره می‌برد.
    *   دی‌بانس (Debounce) کلیدها و کنترل وقفه‌های انکودر نیز در این بخش مدیریت می‌شود.

*   **`Storage.h / .cpp` (مدیریت حافظه غیرفرار):**
    *   رابطی برای تعامل با حافظه NVS میکروکنترلر (کتابخانه `Preferences`). وظیفه بارگذاری (Load) و ذخیره (Save) پریست‌ها (تنظیمات از پیش تعیین شده کاربر) و همچنین ثبت تعداد کل جوش‌های انجام شده را بر عهده دارد.

*   **`WebPanel.h / .cpp` (وب‌سرور و وای‌فای):**
    *   مدیریت ارتباط بی‌سیم (پشتیبانی از حالت‌های STA و AP به صورت خودکار).
    *   یک مینی وب‌سرور داخلی ایجاد می‌کند که پنل مانیتورینگ و تنظیمات (به صورت JSON و HTML) را ارائه می‌دهد. *به دلایل ایمنی، امکان شلیک پالس جوش از طریق این وب‌پنل مسدود است.*

*   **`Spot_Welder.ino` (نقطه ورود برنامه):**
    *   فایل اصلی که به شدت خلوت شده است. تنها وظیفه `setup` کردن ماژول‌های بالا و اجرای توابع در حلقه `loop` را دارد.
